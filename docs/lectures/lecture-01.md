## 本讲要点

- **什么是科研**：科研不等于发论文，好研究也不等于发CCF-A论文；读者读完应当有明确takeaway。
- **好研究的标准**：Solve a Prominent Problem in a Principled Way——重要问题、可泛化、机理清楚、证据充分。
- **第一个项目**：Solve a Meaningful Problem in an Effective Way，先走通流程，再提高“艺术”部分。
- **科研能力**：文献阅读、实现实验、论文撰写、报告展示都需要在实践中熟练；起步阶段的挫折是正常的。
- **科研与工程**：科研回答“为什么”，工程解决稳定性与完整性；现实项目常在两种思维之间切换。
- **研究分类**：理论、系统、算法、应用，各自关注的问题、方法和关键证据不同。
- **项目流程**：定义问题 → 调研相关工作 → 设计解决方案 → 实现与实验 → 论文撰写与交流，过程通常来回反复。
- **科研诚信**：造假、抄袭、违规使用大模型、一稿多投、选择性报告结果都属于越线行为。
