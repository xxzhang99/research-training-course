## 本讲要点

- **按分工选模型**：贵的模型做决定，便宜的模型干活；写作润色与审稿用旗舰模型，批量筛选和整理可以换便宜的。
- **买 API 的坑在渠道不在价格**：只走官方渠道和可查证的中转，不用来路不明的代理 key。
- **每一步的产出都存成文件**：后一步读前一步的文件，过程可追溯、可回退，也方便检查 AI 每次改了什么。
- **每个演示都是三块**：输入（交给 AI 的完整提示词）、输出（AI 的原始回答和写出的文件）、核验（你要检查的一两个点和检查结果）。
- **只依据论文复现**：论文没写清楚的地方列成“待决定清单”自己定；判定标准在运行前写定；写完再用官方实现对照查错。
- **画图交给 AI，口径自己定**：先出图再重绘矢量图，图型与标注标准由你给出。
- **先看出错现场再看演示**：三份课件末尾都列了本课 AI 实际出过的错和避坑清单。
