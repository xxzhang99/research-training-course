<section class="home-section">
<h2>课程简介</h2>
<p>本课程不把文献阅读、方法构思、实验设计和论文写作拆成互不相关的技巧，而是让每个小组围绕同一个研究问题连续推进。课程强调问题的重要性与边界、机理和假设、方案可行性、证据质量、学术诚信，以及对失败和局限的诚实分析。</p>
</section>
