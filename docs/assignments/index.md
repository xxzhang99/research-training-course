# 阶段作业

阶段作业围绕同一个微型研究题目逐步推进。具体发布时间、截止日期与提交入口将在正式开课后更新。

| 作业 | 对应能力 | 建议产出 | 状态 |
|---|---|---|---|
| A1 · 论文阅读 | 识别问题、方法、证据和局限 | Paper Reading Note | <span class="status status-plan">待发布</span> |
| A2 · 文献地图 | 比较多篇论文、组织相关工作 | Literature Map | <span class="status status-plan">待发布</span> |
| A3 · 问题与假设 | 界定边界、解释机理、提出反证 | Problem–Gap–Hypothesis | <span class="status status-plan">待发布</span> |
| A4 · 方案与实现 | 方案、估算、最小实现与风险 | Solution Sketch + MVP Plan | <span class="status status-plan">待发布</span> |
| A5 · 实验与证据 | 基线、变量、指标和有效性 | Evaluation Plan | <span class="status status-plan">待发布</span> |
| A6 · 最终提案 | 汇总完整研究逻辑 | Mini Research Proposal | <span class="status status-plan">待发布</span> |

## 作业设计原则

- 阶段产出应成为最终Proposal的一部分，而不是互不相关的练习；
- 团队成果与个人过程记录同时评价；
- 负结果、复现失败和方案被否定不自动降低成绩；
- 评价重点是研究判断、证据质量、诚实性和修订过程；
- 所有作业需记录AI使用方式和人工核验过程。

## 参考评分维度

- 准确性：是否正确描述问题、方法和证据；
- 完整性：是否覆盖关键逻辑，而非堆积所有细节；
- 清晰度：是否能让同伴理解并复查；
- 批判性：是否识别假设、局限、风险和反证；
- 可执行性：方案与计划能否在课程条件下完成。
