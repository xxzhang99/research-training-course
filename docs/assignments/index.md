## 使用说明

- 解压后，主文件为 `main.tex`；正文分节位于 `Sections/`，图片位于 `Figs/`，参考文献为 `references.bib`，请保留各文件与子目录的相对位置。
- 这是含完整论文示例的模板，不是空白文档。使用时请将标题、作者、正文、图表和参考文献替换为自己的报告内容。
- Overleaf 示例工程为只读分享链接，用于对照目录结构、图表插入和参考文献的写法。
