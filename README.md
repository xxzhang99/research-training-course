# 计算机科研训练课程

本仓库是“计算机科研训练课程”的公开课程网站与资料仓库，使用 MkDocs Material 构建并通过 GitHub Pages 发布。

## 本地预览

```bash
python -m pip install -r requirements.txt
mkdocs serve
```

## 构建

```bash
mkdocs build --strict
```

## 内容结构

- `docs/schedule.md`：课程日程与资料索引
- `docs/lectures/`：各讲课程页面
- `docs/assets/files/`：公开课件与课程文件
- `docs/assignments/`：阶段作业
- `docs/projects/`：贯穿式研究项目
- `docs/resources/`：模板与参考资源
- `docs/policies/`：课程规范

课程网站中的第三方论文和资源原则上只提供官方链接；版权归原作者或出版机构所有。
